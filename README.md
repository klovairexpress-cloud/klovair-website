# Klovair Website

A lightweight, mobile-first landing page for Klovair — a restaurant inventory spreadsheet toolkit.

## Files
- `index.html` — page structure and copy
- `styles.css` — responsive design
- `script.js` — dynamic footer year

## Local preview
Open `index.html` in any browser.

## Deploy
This is a static site and can be hosted on GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any basic web host.

## Contact CTA
Demo and contact buttons open an email to `klovairexpress@gmail.com`.
